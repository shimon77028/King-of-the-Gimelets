# מלך הגימלים · King of the Gimelets

משחק דפדפן בעברית: אתה חייל, ויש לך שבוע אחד כדי לסחוט כמה שיותר ימי גימלים מהקר״פ, ד״ר שמואלי, בלי לסגור שבת ובלי לגמור בכלא.

## איך משחקים

הריצה נמשכת חמישה ימים, ובכל יום יש יעד שעולה: 2, 3, 4, 5 ואז 6 ימי גימלים. לא עמדת ביעד? חוזר לשגרה.

**הביקור אצל הרופא**
- בכל תור בוחרים אחד משלושה משפטים בסיכון נמוך, בינוני או מטורף.
- משפט מטורף יכול להביא ג׳קפוט, או להקפיץ את החשד.
- חשד של 100%: סוגר שבת.
- שלוש הצלחות ברצף נותנות יום בונוס.
- הרופא לא מחכה לנצח: אם פס הסבלנות נגמר, מאבדים משפט.
- המרפאה נסגרת ב־07:12.

**מה עוד קורה בחדר**
- **אירועים מציקים:** החובשת מזהה אותך, הפסקת חשמל, המזגן נופל, הרס״ר בטלפון, בדיקת שתן מפתיעה ועוד.
- **זבוב:** לפעמים זבוב מסתובב בחדר. מי שמרביץ לו מוריד חשד.
- **המ״פ:** מתפרץ לחדר. שותקים ומאבדים חצי מהימים, או רבים איתו ומסתכנים בכלא.

**קרב מכות עם הרופא,** פעם אחת בכל ביקור, בזמן אמת:

| מקש | פעולה |
| --- | --- |
| רווח | אגרוף |
| Enter | בעיטה (שוברת את המגן שלו) |
| ← → | התחמקות לכיוון החץ שמופיע |
| ↓ (להחזיק) | חסימה |
| ↑ | אקמול, פעם אחת |

התחמקות מוצלחת פותחת את הרופא למכות כפולות. הפסד בקרב מוביל לבית דין צבאי.

**בית דין:** יש הזדמנות אחת להתגונן. זיכוי מחזיר אותך לבסיס, הרשעה שולחת לכלא 6.

**בוס סופי:** ביום חמישי הרס״ר מחכה בש״ג.
- הוא שואל ארבע שאלות, ולכל אחת יש 7 שניות.
- שתי טעויות: חצי מהימים נשרפים.

**התקדמות בין ריצות**
- בין הימים בוחרים ציוד שנשאר איתך עד סוף הריצה.
- דרגות קריירה ו־15 עיטורים נשמרים בדפדפן.

במחשב: מקשים 1–3 בוחרים משפט, ו־Enter ממשיך במסכים. בטלפון: כפתורי מגע.

## בטלפון

**אנדרואיד:** [הורדת קובץ ההתקנה (APK)](https://github.com/shimon77028/King-of-the-Gimelets/releases/latest/download/gimelim.apk)
1. פותחים את הקישור בטלפון ומורידים את `gimelim.apk`.
2. פותחים את הקובץ ומאשרים "התקנה ממקור לא ידוע".
3. האייקון "מלך הגימלים" מופיע במסך הבית.

**אייפון:** פותחים את המשחק בספארי, לוחצים **שיתוף ← הוספה למסך הבית**.

בקרב בטלפון: הקשה על החדר היא אגרוף, החלקה הצידה היא התחמקות והחלקה למעלה היא בעיטה. יש גם כפתורים גדולים ורטט כשחוטפים.

## טבלת שיאים משותפת

השיאים נשמרים ב־Supabase (פרויקט `king-of-the-gimelets`). האתר והאפליקציה שולחים אליו ישירות, ואין צורך בהגדרה ב־Vercel.
- אי אפשר לקרוא או לערוך את הטבלה ישירות. יש רק שתי פעולות ציבוריות: `submit_score` ו־`top_scores`.
- ניקוד מעל 150, שם ריק או מזהה לא תקין נחסמים בשרת.
- המפתח שבקוד הוא מפתח ציבורי (publishable), ונועד לשימוש בדפדפן.

## עדכונים

כל דחיפה לענף `main` עולה אוטומטית ל־Vercel, ו־GitHub Actions בונה APK חדש ומפרסם אותו ב־Releases. מי שמשחק באותו רגע מקבל כפתור "גרסה חדשה זמינה". המספר נקבע לפי `version.json`, שחייב להתאים ל־`VERSION` בתוך `index.html`.

## הרצה

זה קובץ אחד, `index.html`, בלי התקנות. פותחים אותו בדפדפן, וזהו.

כדי לשחק אונליין דרך GitHub Pages:
1. בריפו נכנסים ל־**Settings → Pages**.
2. בוחרים **Deploy from a branch**, ענף `main`, תיקייה `/ (root)`.
3. אחרי דקה המשחק זמין בכתובת `https://shimon77028.github.io/King-of-the-Gimelets/`.
